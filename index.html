About Our Project

Smart Recycling Bin is an innovative project designed to encourage recycling and reduce environmental pollution. It uses sensors and an ESP32 microcontroller to detect waste and support smart waste management.

How It Works

01. Detect

The sensor detects objects inside the bin.

02. Process

The ESP32 processes the sensor data.

03. Monitor

The website displays the device status.
